# bot-lab ハンドブック

Claude Code は使えるけれど、他人と同じ repo を育てたことはない——そういう人が、パワーユーザーと同じ repo の共同開発者になるまでに必要なことだけを1ページに集めた教材です。設定一式をコピーして配るのではなく、repo に置ける不変量（規則・完了条件・判断軸）だけを渡す、という方針で作ってあります。例として `bot-lab`（自前の的サイトへ大量の応募を撃って bot 検知のシグナルを読む研究用リポジトリ）が登場しますが、内容は同じ形の他のプロジェクトにもそのまま渡せます。「先に踏まれた3つの穴」の節は、実際にチーム共有で壊れた当事者記録から引いています。

**公開 URL: https://mushataku.github.io/bot-lab-handbook/**
